# Sistema de Labeling (Etiquetado de Navegación)

> **Descripción:** Definición de las etiquetas principales de la interfaz, su ubicación en la navegación y el contenido o funcionalidades que agrupan dentro de la aplicación de experiencias.

## 1. Navegación Principal (Menú Superior / Inferior)

| Etiqueta (Label) | Icono sugerido | Descripción / Contenido que agrupa | Usuarios con acceso |
| :--- | :---: | :--- | :--- |
| **Inicio** *(Página Principal)* | 🏠 | Pantalla de bienvenida, buscador principal, experiencias destacadas y categorías. | Todos *(Invitado, Consumidor, Anfitrión, Admin)* |
| **Explorar** *(Experiencias)* | 🔍 | Catálogo completo con filtros por fecha, ubicación, precio y temática. | Todos |
| **Calendario** | 📅 | Vista cronológica de disponibilidad, fechas reservadas y próximos eventos programados. | Consumidor, Anfitrión, Admin |
| **Mis Reservas** | 🎟️ | Listado de experiencias contratadas (próximas e historial) y acceso a los tickets/entradas. | Consumidor, Anfitrión |
| **Mensajes** | 💬 | Bandeja de entrada y chat directo entre consumidores y anfitriones para resolver dudas. | Consumidor, Anfitrión, Admin |
| **Mi Perfil** *(Apartado Usuario)* | 👤 | Gestión de datos personales, configuración de cuenta, métodos de pago y cierre de sesión. | Consumidor, Anfitrión, Admin |

---

## 2. Etiquetas dentro de una Experiencia (Ficha de Detalle)

| Etiqueta (Label) | Icono sugerido | Descripción / Contenido que agrupa |
| :--- | :---: | :--- |
| **Información General** | ℹ️ | Título, descripción detallada de la actividad, duración, idioma y qué incluye. |
| **Galería** | 🖼️ | Carrusel o cuadrícula de fotografías y vídeos reales de la experiencia. |
| **Disponibilidad** | 🗓️ | Selector de fecha y hora integrado con el calendario para realizar la reserva. |
| **Reseñas** | ⭐ | Valoración media (puntuación) y comentarios verificados de otros usuarios consumidores. |
| **Anfitrión** | 🧑‍🏫 | Ficha resumida del creador de la experiencia, idiomas que habla y botón de contacto. |

---

## 3. Etiquetas de Gestión (Anfitriones y Administradores)

| Etiqueta (Label) | Icono sugerido | Descripción / Contenido que agrupa | Usuarios con acceso |
| :--- | :---: | :--- | :--- |
| **Mis Experiencias** | 📋 | Listado de actividades publicadas, estado (activa/borrador) y edición de datos. | Anfitrión, Admin |
| **Crear Experiencia** | ➕ | Formulario paso a paso para dar de alta una nueva actividad, subir galería y fijar precios. | Anfitrión, Admin |
| **Panel de Control** | ⚙️ | Gestión global de usuarios, moderación de reseñas y supervisión de experiencias. | Administrador |
